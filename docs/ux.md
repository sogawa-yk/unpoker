# unpoker 操作感・演出ガイドライン

> 旅行先の対面プレイで盛り上がることを最優先にする。
> ルールは [rules.md](rules.md)、端末構成は rules.md の付録 B-1 を参照。
> 「未検証」と付けた項目は、実機（iPhone / iPad の Safari）で確かめるまで仮の扱い。

---

## 1. 基本方針

1. **手元（スマホ）で操作し、テーブル（iPad）で盛り上がる**
   操作は手元で静かに行い、結果の発表と演出はテーブルで全員が見る。
2. **触った瞬間に反応する**
   通信を待たずに、端末側で先に動かす（楽観的更新）。サーバーに拒否されたら元に戻す。
3. **見せ場は「溜めてから明かす」**
   公開、順位、入れ替え、勝者はすぐに出さない。テンポよく一呼吸置いてから明かす。
4. **全員が同じ瞬間を見る**
   演出のきっかけはサーバーが出す。iPad とスマホで同時に反応させる。
5. **もたつかない**
   演出はタップで早送りできるようにする。2 ゲーム目以降は、演出を短くする設定も用意する。

## 2. 手札（スマホ）の操作

| 場面 | 操作 | 手応え |
|---|---|---|
| ベット額を決める（親のみ） | チップの山を**上下にスワイプ**して額を変え、「この額で勝負」を長押しで決める | 額に応じてチップの山が高くなる。iPad では親の席にチップの山が積み上がる |
| 3 枚めくる | 裏向きの 7 枚から**指でゆっくりめくる**（隅をつまんで引くと、少しずつ見える） | 自分だけがこっそり見る感じを出す。速くはじけばすぐめくれる |
| 追加でめくる（有料） | 4 枚目以降は、札に「0.25B」の値札が付く。めくるとチップが 1 枚、持ち越しポットへ飛んでいく | 払ったことが周りにも分かる（iPad の席に、めくった枚数が出る） |
| AI に相談 | 画面の隅の 🤖 ボタン。料金を確認してから相談する。答えは数字で出す（例：「この札を場に出すと勝率 +2%」） | 相談中は iPad の席に「🤖 相談中」が出る |
| 1 枚を場に出す | めくった札を**画面の上へはじく** | スマホから札が消え、iPad の場に裏向きの札がすべり込む |
| 3 セット組む | 6 枚を 3 つの枠へ**ドラッグ**する。枠の近くに来たら吸い付く | 入れ替えもドラッグでできる。未確認の札は裏のまま並ぶ |
| 確定 | 「セット確定」を**長押し**（0.5 秒） | 誤操作を防ぐ。押している間、ゲージが溜まる |
| チャレンジ宣言（最下位のみ） | 「チャレンジ（B 点）」と「見送り」の 2 択。カウントダウン付き。他の人のスマホには「最下位が考え中…」 | 宣言はスマホを強く押し込む長押しで行い、重みを出す |
| 便乗（2 位・3 位のみ） | 最下位が宣言した後に「乗る（B 点）」と「見送り」の 2 択。カウントダウン付き | 選んでも、全員が決めるまで他の人には伏せる |
| 強制参加（1 位） | 操作なし。宣言されると、参加費が自動で引かれる演出を出す | 「挑まれた！」と分かる表示 |
| 待ち時間 | 自分の 3 セットと、場札で今できている役を表示する | 待っている間も手札を見ていられるようにする |
| 公開フェーズ（自分の番） | 伏せた 6 枚から 1 枚を選び、**上へはじいてめくる**。中身を知らない札は、自分にとってもめくるまで謎 | めくった札は iPad で表になる。持ち時間 10 秒のゲージを出す |

## 3. テーブル（iPad）の演出

| 場面 | 演出 |
|---|---|
| ルーム待機 | 参加用 QR コード。参加者が入るたびに席に名前が出る |
| ベット額の決定 | 親の席を光らせ、決まった B を大きく出す。各席からチップが中央へ集まる。オールインの席は「ALL IN」を表示する |
| 配布 | 7 枚ずつ各席へ飛んでいく。初期場札は表向きで置かれる |
| 配置中 | 各席の進み具合（めくった枚数、場に出したか、セット完了）を表示する。手の内は見せない |
| 場札公開 | 裏向きの札を **1 枚ずつ、間を置いてめくる** |
| 公開フェーズ【山場 1】 | 手番の席を照らし、選ばれた札がゆっくり表になる。めくるたびに、その席で今できている一番強い役を更新する。役が上がったら（例：ツーペア → フルハウス）大きく演出する。持ち主も知らなかった札のときは「？」から表になる演出で区別する |
| 役判定 | 全員の札がめくれたら、各席の一番強いセットを強調し、役の名前を大きく出す |
| 仮順位 | **最下位から順に**発表し、仮 1 位は最後に出す |
| チャレンジ宣言 | 最下位の席だけを照らし、「考え中…」で溜める。宣言したら大きく「CHALLENGE!」を出し、1 位の席から参加費のチップが中央へ引きずり出される |
| 便乗受付 | 2 位・3 位の席に「考え中…」を出し、全員が決めたら参加者をまとめて明かす |
| チャレンジ宣言（実装） | 宣言が決まったら、画面を暗くして「挑戦」の印を大きく押し、「◯◯ が ◯◯ に勝負を挑みました」を出す（約 2.6 秒、太鼓 2 打）。便乗の判断はその間もスマホで続けられる |
| 場札入れ替え | ①勝負の顔ぶれ: 挑戦・受けて立つ・便乗を 1 人ずつ押印（約 2.8 秒、判子の音）→ ②宣言した人のスマホに大きな「回す」ボタン。押すと、席を暗くした iPad で光が一定の速さで回り続ける（拍子木の刻みと太鼓の拍）。スマホは朱色の「ストップ」に変わる → ③ストップで、今の位置から太鼓の連打の中でだんだん遅くなり、入れ替える札で止まる（約 2.5 秒）→ ④太鼓の一打で札が燃えて消える → ⑤拍子木 2 打で、山札から引いた札をめくる。止めてから結果までのサーバーの待ち時間は 7 秒 |
| 再評価 | 役が変わった席だけ、役の名前を書き換える。逆転したときは席を目立たせる |
| 勝者 | チップが勝者の席へ流れ込み、持ち点の数字がカウントアップする |
| ナッツ | 専用の演出（画面全体のエフェクトと効果音）。最も盛り上がる瞬間として作り込む |

## 4. 音と振動

| 項目 | 方針 |
|---|---|
| 効果音 | **主に iPad から鳴らす**（札をめくる、置く、チップ、ルーレット、勝利、ナッツ）。スマホは自分の操作音だけ、小さく鳴らす |
| 音の再生開始 | iOS は、ユーザーがタップするまで音を鳴らせない。参加時の「タップして開始」で音を有効にする |
| マナーモード | iPhone のマナーモードで効果音が消える可能性がある（未検証）。音は iPad 側を主にする |
| 振動 | iOS Safari は Vibration API に対応していないため、**振動は使えない前提**にする。手応えは音と画面の動きで出す |

## 5. 画面と描画の要件

| 項目 | 要件 |
|---|---|
| フレームレート | 60fps を保つ。動かすのは `transform` と `opacity` だけにする |
| 描画方式 | DOM と CSS の 3D 変形、Web Animations API（札の枚数が少ないので Canvas は不要）。重ければ PixiJS を検討する |
| タッチ操作 | Pointer Events を使う。`touch-action` の設定で、スクロール、ピンチ拡大、ダブルタップ拡大、端からのスワイプで戻る動作を止める |
| 全画面表示 | iPhone の Safari は全画面表示の API に対応していない。「ホーム画面に追加」して PWA として開き、アドレスバーを消す |
| 画面の向き | スマホは縦向き、iPad は横向きを前提にレイアウトする |
| セーフエリア | ノッチやホームバーに操作部品が重ならないようにする（`env(safe-area-inset-*)`） |
| 文字と色 | 札の数字とマークは、テーブル越しにも読める大きさにする。色の違いだけでマークを見分けさせない |

## 6. 素材

- トランプの絵柄、チップ、テーブルの布地は**オリジナルで作る**（既存ゲームの見た目をまねしない）。
- 札は SVG で作り、どの解像度でもくっきり表示する。
- 効果音はライセンスが明確な素材を使うか、自作する。

## 7. 確かめ方

- 最初の段階から **iPhone と iPad の実機**で触って確かめる。シミュレーターやデスクトップのブラウザでは、指での操作感や Safari の癖がわからない。
- 3〜4 人の対面で、実際にテストプレイする。確かめたい点は、待ち時間が退屈でないか、演出がだれないか、操作が迷わずできるか。
- 回線が切れたときと再接続したときにも、演出が崩れないことを確かめる。

### 1 人で確かめる（ボットで席を埋める）

実機を 4 台そろえなくても、自分の iPad やスマホで操作感を確かめられるように、残りの席をボットで埋める。

```bash
npm run bots -- <ルームコード> [人数 1〜3]
```

1. iPad（またはパソコンのブラウザ）でテーブルを開き、ルームコードを控える
2. 自分のスマホで QR コードから参加する
3. 手元のパソコンで `npm run bots -- ABC234 2` を実行すると、「🤖」付きの名前のボットが 2 人入る
4. テーブルで対局を始める。ボットは人と同じくらいの間を置いて操作する。Ctrl+C で止める

| オプション | 効果 |
|---|---|
| `--url https://unpoker.sogawa-yk.com` | 本番に入れる（既定は手元の ws://localhost:8080） |
| `--speed 0.3` | 考える時間を短くする（2 ならゆっくり） |
| `--bold` ／ `--cautious` | いつもチャレンジする ／ しない（チャレンジの演出を何度も見たいときは `--bold`） |
| `--consult` | 判断の前に AI に相談する |
| `--names a,b` | ボットの名前 |

- ブラウザの `/dev`（手元のみ）は、テーブルとスマホ 4 台を 1 画面に並べる。画面の流れを見るのに向くが、指の操作感は実機で確かめる
- 特殊効果カードの画面は、サーバーを `DEV_GRANT_SPECIAL=<種類>`（例 `passRight`）で起動すると、全員がそのカードを持って始まる（本番では効かない）
